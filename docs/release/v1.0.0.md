# v1.0.0 发布说明

## 你将学会什么

了解 MiniAppRuntime-Harmony `v1.0.0` 的发布内容、公开包边界、验证方式和仍需真机确认的范围。

## 发布内容

- OHPM Runtime：`myascf_runtime@1.0.0`
- npm H5 SDK：`@lcy453/miniapp-runtime-harmony-web-sdk@0.1.0`
- 独立消费示例：`examples/npm-har-consumer-demo`
- 九个公开 API、类型化调用封装、API Manifest 与生成文档
- ArkWeb 本地页面、JavaScriptProxy、Promise 回调、超时、取消和 DebugPanel

## 安装

HarmonyOS 工程：

```bash
ohpm install myascf_runtime@1.0.0
```

H5 工程：

```bash
npm install @lcy453/miniapp-runtime-harmony-web-sdk@0.1.0
```

## 兼容组合

| H5 SDK | OHPM Runtime | 状态 |
| --- | --- | --- |
| `0.1.0` | `1.0.0` | 当前公开组合 |

## API 范围

公开能力包括 `runtime.getApiList`、`ui.showToast`、Clipboard、Storage 与 `network.request`。`network.abort` 是 SDK 与 Runtime 之间的内部取消 action，不属于公开类型化 API。

## 验证边界

仓库自动检查覆盖 Manifest、生成文档、SDK 构建与测试、npm pack 以及独立 React Demo 类型检查。HarmonyOS 权限弹窗、剪贴板读取、网络环境和 ArkWeb 真机行为仍应按手工冒烟清单验证。

本说明记录包发布与代码能力，不代表创建 Git tag、GitHub Release 或执行新的 npm/OHPM 发布操作。
